## Getting Started

1. **Prerequisites**: Ensure you have a Linux system with kernel headers installed
2. **Installation**: Follow the [installation guide](installation.md)
3. **Configuration**: Review the configuration options in each component
4. **Deployment**: Use Docker Compose for easy deployment
