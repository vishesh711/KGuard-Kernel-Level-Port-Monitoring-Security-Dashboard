KGuard 2.0.0 is a rewrite of the 2025 prototype: a kernel module and an eBPF
engine that capture every connection attempt, in-kernel detection and
blocking, a backend raising ten kinds of alert, and a live dashboard. How
each item was checked is in [ROADMAP.md](https://github.com/vishesh711/KGuard-Kernel-Level-Port-Monitoring-Security-Dashboard/blob/main/ROADMAP.md).

**Kernel module 3.0.0** (event ABI 2). Builds and passes all 84 kernel checks
on Linux 5.15, 6.1, 6.6, 6.12 and 7.3 in CI.

## Highlights

- **Kernel capture:** IPv4 and IPv6, in, out and forwarded, every network
  namespace, conntrack state, the process behind each connection; lock-free
  per-CPU rings read zero-copy through `/dev/kguard`.
- **In-kernel guard:** port scans (reported 21 ms after the first SYN),
  per-source SYN rate limiting, blocking with expiry, spoofed sources.
  Monitor-only by default; the host's own addresses can never be blocked.
- **eBPF engine and agent:** the same events without a kernel module (XDP and
  TC), DNS and TLS samples, an XDP blocklist; one agent per host ships events
  to the backend.
- **Detections:** scan types, SYN floods, brute force, spoofing,
  amplification, DNS tunnelling, JA3/JA4 TLS fingerprints, OS fingerprints,
  traffic baselines, threat lists. All 8 attack demos pass (35 checks).
- **Operations:** PostgreSQL, Redis, viewer and admin logins, Slack,
  Telegram and e-mail alerts, Prometheus and Grafana, IPFIX export, pcap on
  alert, DKMS install, a systemd unit for the agent.

## Fixes found while preparing this release

- Scan detection could be evaded by probing ports 1024 apart.
- Threat lists and the kernel-alert subscription were skipped for up to a
  minute after the machine booted.
- The production dashboard image could not be built, and called the API on
  the visitor's own machine.

## Known limits

- No measurements on real hardware yet.
- Fuzzing has run for 1.9 hours per parser of the 24 planned; it continues
  nightly.
- What KGuard does not detect, and how it can be evaded: the
  [threat model](https://github.com/vishesh711/KGuard-Kernel-Level-Port-Monitoring-Security-Dashboard/blob/main/docs/THREAT_MODEL.md).

## Install

See [docs/DEPLOYMENT.md](https://github.com/vishesh711/KGuard-Kernel-Level-Port-Monitoring-Security-Dashboard/blob/main/docs/DEPLOYMENT.md).
Assets: the agent for x86_64 (built on Ubuntu 24.04; needs libbpf1, libelf1,
zlib1g and libcurl4), the kernel module source for DKMS, and checksums.
Container images: `ghcr.io/vishesh711/kguard-backend:v2.0.0` and
`ghcr.io/vishesh711/kguard-frontend:v2.0.0`.
