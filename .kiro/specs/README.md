# Historical specs

These are the original 2025 planning documents (requirements, design, task
list) from before the rewrite. They are kept for history and are **not**
maintained: much of what they describe was later replaced (the event format
and transport, the detection rules, the deployment), and the "complete"
statuses in `tasks.md` predate any testing.

The current sources are [ROADMAP.md](../../ROADMAP.md) (what was done and how
it was verified), [docs/DESIGN.md](../../docs/DESIGN.md) and
[docs/README.md](../../docs/README.md).
